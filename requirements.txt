# ---- Media monitoring (YouTube/TV briefing — AWARENESS ONLY, not a trading signal) ----
# Transcripts for tagent/news/youtube_source.py — a robust fallback chain (stop at first success)
# that keeps transcripts flowing even when youtube-transcript-api is IP-blocked:
#   (a) youtube-transcript-api (Korean first; optional PROXY_URL / Webshare from .env)
#   (b) yt-dlp auto-subtitles  (a different endpoint — often not blocked)
#   (c) yt-dlp audio + local Whisper (no caption endpoint -> immune to the IP-block)
# YOUTUBE_TRANSCRIPT_MODE (.env) picks the strategy order:
#   auto (default) = a -> b -> c (cheap captions first, Whisper last);
#   whisper        = Whisper FIRST (c) -> guarantees the FULL video transcript regardless of caption
#                    availability or IP-blocks (uses the GPU per WHISPER_DEVICE); a/b only if c fails;
#   api            = youtube-transcript-api only (a).
# All imported lazily, so the unit tests never need them installed. yt-dlp needs ffmpeg + a JS
# runtime (node/deno) on PATH; faster-whisper is the lighter Whisper backend (no torch).
# Whisper (c) is GPU-aware: WHISPER_DEVICE=auto (default) -> cuda/float16 if a CUDA GPU is present
# (~50x faster), else cpu/int8; override with WHISPER_DEVICE / WHISPER_COMPUTE_TYPE. cuda needs a
# CUDA-enabled torch + faster-whisper's GPU libs (cuBLAS/cuDNN); falls back to CPU if GPU init fails.
# WHISPER_MODEL (.env, default "small") sets the model size: tiny/base/small/medium/large-v3
# (bigger = more accurate but slower; for Korean, small/medium is a good balance).
# Anti-hallucination: faster-whisper runs with condition_on_previous_text=False (no repetition loops
# across windows) and Silero VAD on by default to drop silence/music; WHISPER_VAD=0 turns VAD off.
youtube-transcript-api>=0.6.2
yt-dlp>=2024.0           # list uploads + auto-subtitles + audio download (strategies b/c)
faster-whisper>=1.0      # local speech-to-text for strategy (c); openai-whisper also supported
